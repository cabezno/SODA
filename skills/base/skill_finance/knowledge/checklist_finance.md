# Finance Review Checklist

- [ ] All assumptions are named variables (no magic numbers)
- [ ] Base / Bear / Bull scenarios modeled
- [ ] LTV:CAC ratio calculated and visible
- [ ] Cash runway shown in months
- [ ] Break-even month identified
- [ ] Revenue reconciles to unit count × price
- [ ] Churn applied to recurring revenue cohorts
- [ ] Sensitivity table on top 3 assumptions
