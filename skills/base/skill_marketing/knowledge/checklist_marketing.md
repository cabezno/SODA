# Marketing Review Checklist

- [ ] Value proposition is clear in ≤6 seconds
- [ ] Primary CTA is visible without scrolling
- [ ] Keywords included in title, H1, meta description
- [ ] Analytics events defined for each funnel step
- [ ] Email unsubscribe link present
- [ ] Mobile rendering verified
- [ ] Page load < 3s on 4G
- [ ] A/B test hypothesis defined for main CTA
