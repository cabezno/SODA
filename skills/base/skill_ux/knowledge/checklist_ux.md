# UX Review Checklist

- [ ] Color contrast ≥ 4.5:1 for body text
- [ ] All interactive elements keyboard-accessible
- [ ] Focus indicators visible on all focusable elements
- [ ] Form labels associated (not placeholder-only)
- [ ] Error messages describe the problem and how to fix it
- [ ] Loading states shown for async operations
- [ ] Destructive actions require confirmation
- [ ] Mobile tap targets ≥ 44×44px
- [ ] Empty states designed (no blank screens)
- [ ] Consistent icon + label pairings throughout
