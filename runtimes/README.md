# SODA Runtimes Registry
Este directorio contiene los entornos de ejecución aislados (basados en Docker) que SODA utiliza para desarrollar, probar y ejecutar proyectos.

## Beneficios:
- **Aislamiento Total:** Nada se instala en el sistema host.
- **Consistencia:** El entorno de desarrollo es idéntico al de pruebas.
- **Herramientas Pre-instaladas:** Cada runtime incluye linters, formatters y gestores de paquetes (uv, pnpm, go toolchain).
