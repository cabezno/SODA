# SODA MOBILE TEMPLATE: React Native (Expo)

## Características:
- **TypeScript:** Tipado estricto.
- **Expo Router:** Navegación basada en archivos (similar a Next.js).
- **NativeWind:** Tailwind CSS para React Native.
- **Tamagui o Lucid Icons:** UI optimizada.

## Uso:
Ideal para apps multidispositivo que deben compartir lógica con el backend de FastAPI o Node.
