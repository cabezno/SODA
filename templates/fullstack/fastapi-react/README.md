# SODA MASTER TEMPLATE: FastAPI + React Fullstack
Este es el "piso" estructural para aplicaciones web modernas.

## Componentes:
- **Backend:** FastAPI (Python 3.11+) + SQLModel + PostgreSQL.
- **Frontend:** React + TypeScript + Vite + Tailwind CSS.
- **Infraestructura:** Docker Compose + Traefik (Reverse Proxy).

## Uso en SODA:
El Architect debe copiar esta estructura y el CodeGenerator completará los módulos dentro de `backend/app/api` y `frontend/src/routes`.
